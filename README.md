# 🌙 Pip's Dream Garden — Little dreams grow here.

> Official submission for the **"Baby's First Website"** hackathon by haX.baby. 

Welcome to **Pip's Dream Garden**, a cozy, magical children's storybook portfolio and interactive web experience for **Pip**, the official skull baby and Junior Dream Engineer at the Midnight Nursery.

---

## ✨ Features & Magic

- **The Lullaby Lab:** An interactive music box powered entirely by the browser's native **Web Audio API** with playable melody keys and automatic tune generator.
- **Nightlight Collection:** Interactive light atmosphere switcher (Gold, Lavender, Sunset, Aurora) dynamically adjusting lantern glows.
- **Rooftop Dream Delivery Route:** An animated SVG delivery map tracking real-time dream deliveries across the night sky.
- **Day & Night Atmosphere Mode:** Toggle between a warm cream daytime aesthetic and a deep midnight sky theme.
- **Interactive Garden & Easter Egg:** Clickable flower chimes with particle effects and a hidden secret note from Pip after 5 clicks!
- **100% Free & Open Source:** Zero paid APIs, zero subscriptions, zero backend servers required.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18 & Vite
- **Styling:** Tailwind CSS & Custom CSS Keyframe Animations
- **Audio Engine:** Browser-Native Web Audio API (Zero external audio assets or APIs)
- **Icons:** Lucide React
- **Typography:** Google Fonts (*Playfair Display* & *Fredoka*)
- **Hosting:** GitHub Pages (Static Hosting)
